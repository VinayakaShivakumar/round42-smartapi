# ROUND42 Trader Dashboard V2

Secure, mobile-first static frontend for Cloudflare Pages.

## V2 adds
- NIFTY / GIFT NIFTY / NIFTY Futures ticker strip
- India VIX, USD/INR, global futures, DXY, US 10Y
- MCX Crude, Gold, Silver plus Brent context
- Breadth / gap / sector context
- NIFTY option-chain dashboard with PCR, max pain, ATM straddle, IV and Greeks
- NIFTY futures basis, broker ATP, OI, volume, top-of-book and build-up state
- Existing P&L calendar, trade details, orders, profile and system health
- Paper/live safety status and future STOP/KILL controls remain locked

All displayed market values are DEMO/SAMPLE until `apiBaseUrl` is configured.
